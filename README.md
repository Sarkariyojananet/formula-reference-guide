# Open-Source Finance, Math & Civil Engineering Formula Reference

A clean, verified cheat sheet of commonly used mathematical, financial, health, and civil engineering estimation formulas for students, engineers, and developers.

Live interactive versions of these formulas are hosted at **[AI Free Calculator](https://aifreecalculator.com/)**.
